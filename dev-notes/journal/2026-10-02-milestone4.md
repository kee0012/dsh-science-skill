## 一个必须知道的坑：dev-test 不会重新编译 workspace 包

`pnpm --dir apps/desktop run dev-test` 只把 `science/` 重新同步进 `vendor/science-layer`，
**不重新编译任何 workspace 包**；`vendor/harness` 由 `prepare-runtime.mjs` 用
`pnpm deploy` 从**已构建产物**里搬。所以：

```powershell
# 仓库根，按顺序
pnpm run build                              # 重建 workspace 的 lib/（含 ui-science）
node apps/desktop/scripts/prepare-runtime.mjs   # 刷新 vendor/harness
pnpm --dir apps/desktop run dev-test        # 出免安装测试版（可加 --launch）
```

只跑 dev-test = 你看到的还是上一轮的 `lib/client.js`。
（`prepare-runtime` 里的 `syncWebFrontendArtifact()` 会在 `apps/web/dist` 与
`resources/web-frontend-dist` 不一致时**用重建结果覆盖权威前端**——那属于发布敏感面，
要不要重建前端得先问过用户。）
